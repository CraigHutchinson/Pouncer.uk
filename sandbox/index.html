Module viewer bench

A workbench for the WebGL module viewer before it goes anywhere near a real page. This directory is excluded from the published site by the deploy workflow.

Constraints this has to satisfy. three.js is vendored into sandbox/vendor/ and imported through an import map — never from a CDN, because the privacy page states that nothing is fetched from a third party. The library is 2.1 MB unminified, so on a real page it must load on demand, behind a poster and an explicit action, never on page load.
